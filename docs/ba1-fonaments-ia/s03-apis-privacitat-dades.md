## Objectius

En acabar la sessió has de ser capaç de:

1. Distingir els tipus de llicència de les eines d'IA que farem servir.
2. Determinar quines dades es poden introduir a cada eina i quines no.
3. Redactar un informe breu de riscos amb estructura professional.

## Continguts

- Què és una API d'IA (sense programar) i per què les empreses no fan servir el xat.
- Com es paga una API i què implica això per al disseny d'un producte.
- Privacitat: què passa amb el que escrius a una IA.
- RGPD i polítiques d'ús: quines dades pots posar a cada eina i quines no.
