**BA1 — Fonaments i infraestructura d'IA** · 3 h

## Objectius

En acabar la sessió has de ser capaç de:

1. Escriure un prompt amb instrucció, context i format de sortida diferenciats.
2. Configurar un system prompt i demostrar com canvia el comportament del model.
3. Fer servir la IA per diagnosticar una incidència tècnica i valorar-ne la resposta.

## Continguts

- Anatomia d'un prompt: instrucció, context i format de sortida.
- Què és un system prompt i per què canvia el comportament del model.
- Errors habituals de prompting i com detectar-los.
- Preparació de l'examen de bloc.
